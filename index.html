Final Year Engineering Project

Underground Cable Fault Distance Locator Using Arduino Uno

An Arduino Uno-based system designed to estimate the distance of faults in underground electrical cables using electrical resistance measurement and Ohm’s law.

Key features

  • Fault distance estimated from measured resistance via Ohm’s law
  • ADC-based acquisition of the sensing voltage
  • Circuit verified through Proteus simulation
  • Custom PCB designed and hardware prototype built
  • Low-cost, portable fault-location setup
